# SteamCardToolkit

Steam 集换式卡牌批量上架油猴脚本。

直接调用 Steam 自身的库存与市场接口完成批量上架，**不依赖页面 DOM**，
因此不会因为 Steam 改版而失效。

---

## 功能

- **一次拉取全部社区物品** —— 卡牌、闪卡、表情、背景、宝石一次读全，不需要翻页
- **按市场最低价批量上架** —— 自动完成手续费反推，挂出价等于当前最低价
- **普通卡 / 闪卡分开筛选** —— 手动勾选上架范围，不做默认批量
- **面板可折叠成页边小标签** —— 不用时收成一条竖标签贴在右边缘，不挡库存页

[**→ 点此安装**](https://greasyfork.org/zh-CN/scripts/597172-steamcardtoolkit)

从油叉安装的用户，更新由油叉托管，会自动收到新版本。

### 方式二：手动安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开 [`SteamCardToolkit.js`](./SteamCardToolkit.js)，点右上角 `Raw`
3. Tampermonkey 会弹出安装页，确认即可

## 使用

1. 打开自己的 Steam 库存页（`steamcommunity.com/id/<你的ID>/inventory`）
2. 右上角出现面板，点 **加载库存**
3. 点 **查询价格**，等列表显示出每张卡的最低价与「到手」金额
4. 勾选要卖的卡（可用筛选只显示普通卡或闪卡）
5. 点 **批量上架选中项**
6. **打开 Steam 手机 App，在「确认」页面批量勾选确认**

> 第 6 步不能省略。没有确认的上架不会生效。

## 重要说明

### 手机令牌是硬约束

如果你的账号启用了 Steam 手机令牌，上架接口只能「发起」请求，
真正生效必须在手机 App 里确认。脚本无法绕过这一步（绕过需要你的令牌密钥，
那不该由脚本持有）。

好消息是手机确认页**支持批量勾选**，所以正确用法是：
脚本一次性发起若干笔 → 到手机上一次性全部确认。

面板里的「每批上限」就是控制一次发起多少笔的，默认 30。

### 手续费会吃掉低价卡的大部分收益

这是最容易误判的地方。Steam 的各项费用都有最低值兜底，
所以价格越低的卡，手续费占比越夸张：

| 市场最低价 | 你实际到手 | 手续费 |
|---|---|---|
| ¥0.21 | **¥0.07** | ¥0.14 |
| ¥0.28 | ¥0.14 | ¥0.14 |
| ¥0.50 | ¥0.36 | ¥0.14 |
| ¥1.00 | ¥0.85 | ¥0.15 |

¥0.21 的卡卖出去，**三分之二被手续费拿走**。

所以面板列表里同时显示「最低价」和「到手」两个数字 —— 请按「到手」判断值不值得卖。

### 定价机制

Steam 的上架接口接收的参数是**卖家实收金额**，不是买家支付价。
脚本的定价链路是：

```
市场最低价（买家支付）
   └─ 反推 ─→ 卖家实收  ← 这个值提交给上架接口
        └─ 回算 ─→ 买家支付（与市场最低价持平）
```

反推用的是 Steam 自身的费用计算函数，脚本内另有一份等价实现作为兜底，
两者已逐点对拍验证一致。

### 限速

脚本对市场接口做了串行限速（查价 1.5 秒/次、上架 1.2 秒/次）与结果缓存。
批量操作会慢，但这是刻意的 —— 高频请求有触发 Steam 风控的风险，
被封禁的代价远大于多等几分钟。
